# Roadmap

## Phase 1 - Foundation

1. Finalize schema and tool contracts.
2. Set up app skeleton and environment configuration.
3. Prepare sample recipes for testing.

## Phase 2 - Core MVP Flow

1. Implement recipe parsing via Gemini.
2. Implement review/edit UI.
3. Implement Notion save and retrieval.
4. Wire agent with custom tools.

## Phase 3 - Validation

1. Run extraction and hallucination tests.
2. Validate agent query behavior.
3. Improve prompts and error messages.

## Phase 4 - Demo Readiness

1. Deploy to Streamlit Community Cloud.
2. Final smoke test and script demo scenarios.
3. Freeze MVP scope.

## Post-MVP Backlog

1. MP4/Reel upload parsing.
2. Improved semantic query handling.
3. Duplicate detection.
